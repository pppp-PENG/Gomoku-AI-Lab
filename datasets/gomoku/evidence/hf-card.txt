# Datacard: Gomoku (Five in a Row) AI Dataset

## Dataset Description

### Dataset Summary
The Gomoku (Five in a Row) AI Dataset contains board states and moves from 875 self-played Gomoku games, totaling 26,378 training examples. The data was generated using WinePy, a Python implementation of the Wine Gomoku AI engine. Each example consists of a board state and the corresponding optimal next move as determined by an alpha-beta search algorithm with pattern recognition.

### Supported Tasks
- **Policy Prediction**: Predicting the next optimal move given a board state
- **Game State Evaluation**: Assessing board positions
- **Reinforcement Learning**: Training Gomoku-playing agents
- **Pattern Recognition**: Learning common Gomoku patterns and strategies

### Languages
Not applicable - this is a board game dataset with numerical representation.

## Dataset Structure

### Data Instances
Each instance in the dataset consists of:
- A board state (15×15 grid)
- The next move made by the AI (coordinates and player)

Example instance (in sparse representation):
```json
{
  "board_state": [112, -96, 95, -110], 
  "next_move": -67
}
```

Where:
- `board_state`: List of positions where pieces are placed (positive integers for black, negative for white)
- `next_move`: The next move (positive for black, negative for white)

### Data Fields
In the full board format:
- `board_states.npy`: (N, 15, 15) array where 0=empty, 1=black, -1=white
- `next_moves_coords.npy`: (N, 2) array with (x,y) coordinates
- `next_moves_players.npy`: (N,) array with player indicators (1=black, -1=white)

In the sequence format:
- `board_states.json/pkl`: List of sparse board representations
- `next_moves.json/pkl`: List of next moves
- `complete_games.json/pkl`: List of complete game sequences

### Data Splits
The dataset is divided into training (80%) and test (20%) sets:
- Training: ~21,100 examples from ~700 games
- Testing: ~5,278 examples from ~175 games

The split is performed at the game level to ensure that the test set evaluates the model's ability to generalize to completely unseen game situations.

## Dataset Creation

### Source Data
The dataset was generated through self-play using the WinePy AI, a Python implementation of the Wine Gomoku AI engine. No external or human gameplay data was used.

### Annotations
The moves in this dataset are not human-annotated but are instead determined by the AI's alpha-beta search algorithm with pattern recognition. The search depth varies but is typically between 4-10 plies.

### Personal and Sensitive Information
This dataset does not contain any personal or sensitive information.

## Considerations for Using the Data

### Social Impact of Dataset
This dataset is intended to advance research in AI for board games, particularly Gomoku. It may contribute to developing stronger game-playing agents and improving understanding of decision-making algorithms in perfect information games.

### Discussion of Biases
The dataset is generated by a specific AI algorithm and may reflect biases inherent in the algorithm's evaluation function and search strategies. This may bias models trained on this data toward particular play styles or strategies.

### Other Known Limitations
- The AI that generated these games is not perfect and may not always play optimally
- The dataset does not include games against human players or diverse AI opponents
- The AI may have particular strategic preferences that are over-represented in the dataset
